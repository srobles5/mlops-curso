## E4 · Pipeline CI/CD automatizado (20 %)

Se avanza el sábado del fin de semana 2 y se termina en el taller del viernes del fin de semana 3. Lo que falte se puede completar hasta el siguiente fin de semana sin perder puntos.

### Checklist mínimo (Satisfactorio)
- [ ] Pruebas en `tests/` y workflow de CI que corre en cada PR
- [ ] Las reglas de `master` y `entrega/*` exigen que el CI pase
- [ ] El entrenamiento registra el modelo en el MLflow de DagsHub
- [ ] La API está en un Space de Hugging Face y se actualiza con un merge, sin pasos manuales
- [ ] Los tokens están en GitHub Secrets y en ningún archivo del repositorio
- [ ] PR de `entrega/e4` hacia `master`

### Para subir de nivel (Destacado o Excepcional)
- El CI también construye la imagen y prueba el contenedor
- El CI falla si la métrica del modelo baja de un umbral acordado
- El CD espera a que el CI pase antes de desplegar

## E3 · Modelo y API en un contenedor (10 %)

Se empieza el viernes del fin de semana 2 y se revisa el sábado, después de 45 minutos de taller en clase. Revisión de 2 a 3 minutos en la mesa del equipo. Lo que falte se puede completar hasta el inicio del fin de semana 3 sin perder puntos.

### Checklist mínimo (Satisfactorio)
- [ ] `api/app.py` con `/health` y `/predict`, y la entrada validada con Pydantic
- [ ] `Dockerfile` y `requirements-api.txt`
- [ ] `docker run` levanta la API y `/predict` responde con una fila real del dataset
- [ ] README que explica cómo construir, correr y probar
- [ ] PR de `entrega/e3` hacia `master`

### Para subir de nivel (Destacado o Excepcional)
- Imagen más liviana, con solo lo necesario
- El contenedor corre con un usuario que no es root
- Configuración por variables de entorno
